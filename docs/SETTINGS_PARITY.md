# 设置迁移对照（Build 5）

原版基线：d9470b11297ea7948e5711491b73f6756c170dfe。八分类标题、描述及顺序来自 `SettingsRootCategoryPolicy.kt`；首页层级参考 screenshot2.png。

`ANDROID_SETTINGS_INVENTORY.json` 保存 384 个原始标题引用位置（包含重复项与插值，并非 384 个独立功能）。未声称整个设置模块已实现。

## 默认值

自动播放 true、刷新数量 20、弹幕透明度 0.85、显示区域 0.5、滚动时间 7 秒与原版对应常量对齐。iOS 固定画质预设、字体离散档位、AVPlayer 原生控件不声称与 Android 实现完全相同。

## 备份与插件行为

备份采用白名单，不导出 Cookie、SESSDATA、账号、搜索历史或播放位置。导入先完整校验格式、类型、范围和插件规则，再经确认应用；验证失败不部分修改。WebDAV 使用无 Cookie、无凭证缓存的临时会话，拒绝跳转，用户名密码仅保留在页面内存。云备份为完整 HTTPS 文件地址，父目录须已存在。

未支持的插件动作/字段明确拒绝导入；不显示无效开关。普通 JSON 规则为声明式过滤，不执行代码。
