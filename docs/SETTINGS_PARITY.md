# 设置迁移对照（Build 7）

原版基线：`d9470b11297ea7948e5711491b73f6756c170dfe`。八分类标题、描述及顺序来自 `SettingsRootCategoryPolicy.kt`；分类内入口来自 `SettingsSections.kt` 的 `SettingsRootCategoryContent`；播放选项来自 `PlaybackSettingsScreen.kt`。iOS 使用原生表单、导航、颜色选择器、身份验证、AVKit 和文件选择器。

**尚未达到“全部功能与 UI 一模一样”。** 原版有大量依赖 Android 播放器、插件和存储的能力。以下明确区分已经接入运行时的选项与未实现项，不以分类数代替功能完成度。

`ANDROID_SETTINGS_INVENTORY.json` 保存 384 个原始标题引用位置，包含重复项和插值，不是 384 个独立功能。

## 本轮设置入口修正

- 外观与主题 → 外观设置。
- 播放与画质 → 播放器设置；互动与评论 → 互动、评论与内容预览。
- 首页与推荐 → 首页展示 → 首页样式与推荐卡片；推荐流与动态单独分组。
- 导航与交互 → 导航与标签；交互与动效 → 动效与触感。
- 隐私与权限、存储与备份、插件与扩展、系统与关于保留对应入口。

## 备份与默认值

新增选项纳入备份白名单，校验枚举、范围、顶部项目唯一性、底栏项目全集和颜色格式；未知项或错误格式整包拒绝，不部分导入。Cookie、账号、搜索历史、播放位置及上次缓存清理时间不会导出。旧 Build 5 备份可继续导入；缺失字段保留当前值。

WebDAV 临时会话无 Cookie/凭证缓存，拒绝重定向，用户名密码只留在页面内存。父目录须事先存在。

自动播放 true、刷新数 20、弹幕透明度 0.85/区域 0.5/时间 7 秒与原版对应默认值对齐。其余 iOS 新增默认值是当前实现策略，未宣称全部等同 Android。

## 验证

Actions 在 iPhone 模拟器上检查设置导航、开关持久化、备份搜索、媒体播放、评论分页/重试/去重、画质策略优先级、速度记忆、分 P 完成策略、缓存周期及备份校验。新增操作回归覆盖实际 AVKit 全屏按钮、返回后视频帧更新，以及楼中楼加载第二页和父回复引用。最终执行结果以对应 Release 链接的 Actions run 为准。

尚无用户 iPhone 上的对照验收，不能以模拟器通过替代真机所有视频源、PiP 或像素级 UI 一致性。

## Build 7 字幕

在 DASH → HLS 桥接中添加原生 WebVTT 字幕轨道；按需下载与转换 B 站 JSON 字幕，使用 AVKit 字幕菜单切换，原生全屏可以使用同一字幕轨道。设置入口是“播放与画质 → 互动、评论与内容预览 → 自动启用字幕”。支持关闭、开启、仅非 AI、自动；新视频按播放器当时是否静音选择自动模式的 AI 策略，不会覆盖播放途中用户手动选轨。

字幕名称会被 iOS 本地化，因此使用稳定的 HLS CHARACTERISTICS 标识匹配轨道，避免同语言的 AI/人工字幕混淆。元数据获取与播放地址请求并行，字幕查询有 4 秒超时，不将字幕查询错误变成视频播放失败。

尚未实现 Android 双语同时显示、字幕自定义样式/偏移、单段 MP4 字幕注入；部分字幕需要 B 站登录权限。不能据此称字幕模块已与原版完全对等。

## Build 8

“播放与画质 → 播放器设置”新增“进入视频自动全屏播放”，默认关闭。开启后视频准备好时以 iOS 全屏呈现 AVKit 播放器，同时自动播放；同一页面内手动退出后不重复弹出。普通视频和番剧使用这一行为，听视频不自动全屏。新设置纳入备份白名单。

个人页补回关注/粉丝数量及可点击关注入口，另有“我的关注”菜单；关注列表采用原版 `/x/relation/followings` 参数进行原生分页，失败重试、账号切换清空旧数据。UP 主空间目前仍是网页。

未将上述补项计为完整设置或个人页 UI 对等。仍缺原版完整个人页结构、动态统计、原生空间和此前记录的设置功能。
