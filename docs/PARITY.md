# 功能对照与验收

基线：upstream.json。只把已实现、已编译、已实机对照分别记录，不混用状态。当前无 iPhone 实机验收证据，不承诺像素级一致。

| 模块 | 当前移植状态 | 尚缺能力 |
|---|---|---|
| 首页 | 原生推荐 / 热门 / 排行榜、分页刷新、双列及 iPad 自适应 | 分区、长按预览、整卡共享转场 |
| 搜索 | 原生视频搜索、分页、本地历史 | UP/番剧/文章分类、实时建议、热搜 |
| 登录 | 原生 Web 扫码、Cookie 导入，Keychain 保存 | TV 授权、手机密码、短信、多账号 |
| 视频 | AVPlayer 单段 MP4、DASH AVC/AAC 本机 HLS 桥接、原生全屏/PiP 控件、倍速、分集、进度记忆 | 手动画质切换、HEVC/HDR、预览章节、完整后台生命周期验收 |
| 弹幕 | Protobuf 分段加载、普通滚动/顶部/底部弹幕、开关 | 高级弹幕、发送、过滤/密度设置；原生全屏/PiP 不显示叠加弹幕 |
| 互动 | 点赞、投币确认、稍后再看、系统分享、首屏评论 | 收藏操作、评论发布/分页/回复、关注 |
| 动态 | 原生关注流、图文/视频卡片、分页 | 转发嵌套、GIF、图片保存、评论、发布 |
| 历史/收藏 | 原生历史分页、收藏夹及内容分页 | 删除/批量管理/播放队列 |
| 番剧/直播 | 原生目录分页、番剧选集及播放、直播 HLS 播放 | 季度切换/追番、直播弹幕/分区/关注；待真机验证 |
| 消息/空间 | 明确标识的网页入口 | 原生移植未完成，不计入原生功能覆盖 |
| 设置 | 原生主题、账号退出、来源信息 | 大部分原版设置、图标切换、本地化 |
| 离线缓存 | 未实现 | 断点续传、任务管理、合并、本地播放 |
| 听视频 | 原生封面、稍后再看队列、上一首/下一首、播放暂停 | 自动续播、歌词、黑胶动画、定时、跨页面常驻播放器 |
| 视频笔记 | 未实现 | 编辑、同步、分享、AI 总结 |
| 插件/投屏/备份 | 未实现 | JSON 规则、Anime4K、DLNA/Cast、WebDAV |
| 构建更新 | Actions 测试/打包/上游发布检查 | Apple 签名、自动安装；新功能仍需编写 |

## 验收方式

1. 构建门禁：Xcode 编译、WBI 已知向量与数据映射测试。
2. 接口验收：游客/登录/过期登录/风控/无网络各状态。
3. 媒体验收：音画同步、切换分集、返回、后台/锁屏、PiP、AirPlay、横竖屏。
4. 视觉验收：同数据源下与 Android 截图对照，浅深色及 iPad；原生返回/分享/弹窗按 iOS 行为验收。
5. 功能矩阵全量追踪：ANDROID_FEATURE_MATRIX.md 为上游原文。
