基线：upstream.json。只把已实现、已编译、已实机对照分别记录，不混用状态。当前无 iPhone 实机验收证据，不承诺像素级一致。

## 验收方式

1. 构建门禁：Xcode 编译、WBI 已知向量与数据映射测试。
2. 接口验收：游客/登录/过期登录/风控/无网络各状态。
3. 媒体验收：音画同步、切换分集、返回、后台/锁屏、PiP、AirPlay、横竖屏。
4. 视觉验收：同数据源下与 Android 截图对照，浅深色及 iPad；原生返回/分享/弹窗按 iOS 行为验收。
5. 功能矩阵全量追踪：ANDROID_FEATURE_MATRIX.md 为上游原文。

## Build 9 开发中的增量

- 设置首页按 `SettingsVisualSpec.kt` 对齐：左右 16、行垂直 12、图标容器 36、图标间距 14、分组圆角 14；支持字体缩放。子页尚未全部视觉对齐。
- 视频卡片不再固定封面高度；默认 16:10，可选 16:9/4:3。时长封面外/封面内无底色/隐藏、紧凑统计、完整标题均有实际渲染消费者与备份白名单。
- 原生空间的 WBI 资料接口游客实测 code 0；WBI 投稿及原版聚合备用接口在当前服务器网络均返回 HTTP 412。保留失败与重试，不标作联网验收通过。
- 评论写入与收藏变更只在用户按发送/完成时提交，失败保留草稿/选择；未使用用户凭证执行真实写入测试。
- 这些改动不等于原版全量功能移植完成。最终构建和截图记录见 VALIDATION.md。
